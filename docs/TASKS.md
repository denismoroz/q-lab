# Задачи

Реализация — sonnet-субагенты, ревью — opus. Один таск = один модуль, непересекающиеся
пути, тесты обязательны. Коммитит ревьюер после проверки.

## M2 — ядро: от спека до вердикта

| id | задача | пути | статус |
|---|---|---|---|
| T9 | слой данных: снапшоты, универс с делистнутыми | `src/qlab/data/` | ✅ |
| T10 | стенд: accrual, косты, метрики, min_capital_usd | `src/qlab/harness/` | ✅ |
| T11 | склейка `qlab evaluate`, маршрутизация вердикта | `src/qlab/pipeline/` | ✅ |
| T12 | три стратегии для приёмки | `src/qlab/strategies/` | ✅ |
| T13 | реестр площадок: venue_supported, atomic_execution | — | ⏳ |
| T14 | приёмка M2: прогнать FRAB, Bv2, Trend | — | ⏳ |

**T13 — почему нужен.** `qlab evaluate` не может вернуть `paper` ни для чего: правила
требуют `venue_supported`, `data_forward_available`, `atomic_execution`, а бэктест их
вывести не может — это факты об инфраструктуре, не о рынке. Синтезировать их запрещено.
Нужен маленький реестр возможностей площадок: `data_forward_available` выводится из
источника снапшота, `venue_supported` — из наличия адаптера исполнения (сегодня только
HL), `atomic_execution` — из числа одновременных ног стратегии и свойств площадки.

Статус: T1 ✅ · T2 ✅ · T3 ✅ · T4 ✅ · T5 ✅ · T6 ⏳

## Приёмка M1 (2026-09-20)

Конвейер проходит целиком: `init-db` → `import-graveyard` → три запроса → воронка.

| проверка | результат |
|---|---|
| цитаты сверены с исходниками | 79 из 79 |
| импортировано | 11 драйверов, 18 идей, 79 вердиктов |
| умерли по отменённым правилам | 4 идеи, 5 вердиктов |
| дозрело для перепроверки | 1 (и 51 вердикт без датировки) |
| тесты | 119 passed |

Главный запрос возвращает обе стратегии, которые владелец воскресил вручную —
cross-exchange spread и trend TSMOM, обе убиты декорреляцией.

**Что вскрылось про старый процесс:** 60 вердиктов из 79 на стадии «реален ли эдж»
против одного на исполнимости; 21 число не имело под собой критерия; 51 вердикт без
диапазона данных, поэтому автоматическое дозревание кладбища почти не работает —
сначала нужна датировка.

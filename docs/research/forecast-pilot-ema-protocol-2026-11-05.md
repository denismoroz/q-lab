# Прогноз на одной монете: признаки EMA — дополнение к протоколу (2026-11-05)

Записано до расчёта варианта с EMA. Владелец: «а если добавить какие EMA в фичи?» Основной расчёт пилота
(без EMA) в этот момент уже идёт; его результатов я ещё не видел; он не пересчитывается и не перевыбирается —
вариант с EMA показывается **рядом**, как добавление.

**Признаки EMA** (по часовым закрытиям, только прошлое, без цены — в долях размаха; размах σ — разброс часовых
логарифмических доходов за прошлые 720 часов):
- (закрытие / EMA_n − 1) / (σ·√n) для n ∈ {12, 24, 72, 168, 720} часов — 5;
- пересечения (EMA_быстрая − EMA_медленная) / (закрытие·σ·√n_медленная) для (12, 72), (24, 168), (72, 720) — 3;
- наклон каждой EMA за n/4 часов: (EMA_n(t) − EMA_n(t − n/4)) / (закрытие·σ·√(n/4)) — 5.

Итого 13 признаков. **Два варианта:** «основа + EMA» (26 + 13 = 39 признаков) и «только EMA и долгие доходы»
(13 + доходы за 1, 7, 30 дней + доход BTC за 7 дней = 17) — чтобы увидеть, дают ли EMA что-то сверх наклонов
слоёв волн и долгих доходов, которые уже есть в основе.

**Всё остальное — как в основном протоколе и дополнении о классах**: те же цели (z-доходы и классы «падение» /
«рост»), модели и сетки (гребневая / логистическая, бустинг, малая TCN), обучение раз в полгода с 2022-01,
пауза = горизонт + 1 сутки, граница 2024-06-12, выбор только по первому отрезку, перемешанная цель (правило
остановки то же).

**Испытаний добавляется:** на вариант — регрессия 24, классы 80, перемешанная цель 40 = 144; два варианта —
**288**.

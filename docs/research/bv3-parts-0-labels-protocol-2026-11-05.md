# Bv3 по частям. Шаг 0: метки больших падений — протокол (2026-11-05)

Записан до расчёта. Владелец, 2026-11-05: «мы решаем задачу очень высокоуровнево. нужно распилить её на
части и пробовать улучшить каждую под задачу»; «если посмотреть у каждой монеты свой тренд и своя
инерция»; «да».

**Зачем.** Каждая часть решения (фаза, включение, выключение, повторное включение, размер, издержки)
настраивается под свою мерку, а мерки считаются по размеченным большим падениям. Метки — только
линейка: они знают будущее (где был верх и дно). Любое решение читает только прошлое.

**Данные.** Binance, 2019-09-08 … 2026-10-30; набор (а) BTC, ETH, SOL, AVAX; набор (б) — десятка по
обороту (в мерках участвуют часы, когда монета в десятке). Цена — дневные закрытия контракта.
Граница первых 2/3 — 2024-06-12; падение относится к отрезку по дню верха.

**Разметка (зигзаг).** Цена делится на чередующиеся ходы вниз и вверх: ход заканчивается, когда цена
развернулась от своего крайнего значения не меньше чем на X. **Большое падение** — ход вниз глубиной
не меньше X и длиной от верха до дна не меньше N дней; у него есть верх, дно и **отскок** — следующий
ход вверх (от дна до следующего верха).

**Сетка определений.** X ∈ {0.15, 0.25, 0.35}, N ∈ {7, 14} — 6 определений. **Основное — X = 0.25,
N = 7**: по нему настраиваются и судятся части. Для остальных пяти — чувствительность: сколько падений,
и мерки боевого правила по ним.

**Отчёт.** По каждому определению и набору: число падений на каждом отрезке, средняя глубина и длина,
средний отскок; по основному — таблица падений. Испытаний нет.

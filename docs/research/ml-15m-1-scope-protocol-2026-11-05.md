# Модель на деньгах: одна на все монеты или своя у каждой — дополнение к протоколу (2026-11-05)

Записано до любого расчёта (вместе с `ml-15m-0-protocol`, до первого прогона). Владелец: «я не уверен что одна
модель на все монеты - подойдет... может нужна модель под каждую монету?»

**Три охвата модели:**
1. **Общая** — одна модель на четыре монеты, монета — признак (как в основном протоколе).
2. **Своя у каждой** — отдельная модель на каждую монету, обучается только на её данных; монета как признак
   не нужна; тот же объём обучения (60 пакетов × 3 прохода на каждое переобучение).
3. **Общая, дообученная под монету** — на каждом переобучении сначала общая модель, затем для каждой монеты
   её копия дообучается 20 пакетами только на данных этой монеты с шагом обучения ×0.3.

**Порядок, чтобы не раздувать перебор.** Сначала основная сетка в охвате «общая» (2 шага × 2 модели × 3
штрафа = 12) — для каждой пары «шаг, модель» выбирается штраф по первому отрезку. Затем для этих четырёх пар
— охваты 2 и 3 (**8 испытаний**). Для каждого шага выбирается лучшее из шести «модель × охват» по деньгам
упрощённой модели на первом отрезке.

**В книгу:** для каждого шага и каждого охвата — лучшая из двух моделей по первому отрезку: 2 шага × 3 охвата =
**6 прогонов книги** (вместо 2 в основном протоколе).

**Отчёт:** все варианты на последней трети; по каждой монете — деньги упрощённой модели и изменения доли; рядом
с числом параметров — действительный размер выборки по монете: число больших падений монеты (≥ 25%, ≥ 7 дней)
в обучении к началу 2022 года и к последнему переобучению, и число ходов зигзага (смен направления на 25%) —
«смен режима». Если модель «своя у каждой» явно переобучается (большой разрыв между первым отрезком и
последней третью), это будет сказано прямо.

**Испытаний всего:** 12 + 8 + 6 = **26**.

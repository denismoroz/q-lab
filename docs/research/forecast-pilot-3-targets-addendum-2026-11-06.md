# Прогноз, шаг 3 — поправка до расчёта: две простые цели (знак и тройной барьер) (2026-11-06)

Записано до расчёта этих целей. Владелец: «а не слишком ли намудрено с target»; «да, добавляй обе». Расчёт основной
цели (z-доход и классы k = 1, протокол `forecast-pilot-3-protocol-2026-11-06.md`) уже идёт; новые цели —
**добавление рядом**, ничего уже выбранного не перевыбирается.

## Общее

- Монеты: BTC, ETH, SOL, AVAX, каждая сама по себе.
- **Вход — тот вариант (б / д), который монета выбрала на основной цели** по первому отрезку (не перевыбирается;
  так вдвое дешевле, а на BTC варианты не различались).
- Модели: логистическая (C = 0.1) и бустинг (лист ≥ 1 000); выбор между ними — по первому отрезку. TCN нет.
- Переобучение раз в полгода с 2022-01, пауза = горизонт + сутки (окно барьера не длиннее горизонта, поэтому пауза
  покрывает его целиком), граница 2024-06-12.
- Отсчёт: 50 розыгрышей «другой день + сдвиг часа» для каждой монеты, модели и цели; засчитывается только то, что
  выше 95-го процентиля **на обоих отрезках**.

## 1. Знак

- Метка: «вверх», если ln C(t + h) − ln C(t) > 0; без вычитания среднего и без порогов. h = 1 час, 4 часа, 1 день.
- Оценка «вверх» — вероятность модели минус доля «вверх» в обучении этого полугодия (знак оценки — ответ модели).
- Меры: доля угаданных направлений и AUC. Отсчёт «прошлый знак»: знак прошлого дохода за h; его сторона
  (продолжение или разворот) выбирается по первому отрезку.
- Засчитывается: доля угаданных и AUC выше 95-го процентиля отсчёта **и** доля угаданных выше, чем у «прошлого
  знака», на обоих отрезках.

## 2. Тройной барьер (López de Prado)

- От каждого часового решения: верхний барьер ln C(t) + kσ, нижний ln C(t) − kσ, σ — разброс h-часовых доходов,
  закончившихся к t, за последний год (как масштаб основной цели; только прошлое); вертикальный барьер — горизонт.
- Метка — **какой барьер цена коснулась первой**, по минутным ценам закрытия внутри окна: вверх / вниз / время
  вышло. Если в окне есть пропуск минут — метки нет. Доли трёх исходов — в отчёте.
- h = 1 час, 4 часа, 1 день; **k = 1.0 и 1.5**.
- Две модели «один против остальных»: «первым — верх» и «первым — низ».
- Отсчёт размаха (недавний размах + час + день недели) — тот же; он должен предсказывать «барьер будет задет», но
  не какой.
- Засчитывается знание стороны: AUC модели по стороне выше 95-го процентиля отсчёта на обоих отрезках **и**
  интервал разницы «(верх − низ) модели − (верх − низ) отсчёта размаха» не содержит ноль, с одним знаком на обоих
  отрезках. Отчёт также: AUC по сторонам рядом с отсчётом размаха, «верх − низ» модели с интервалом.

## Испытания

Кандидаты на монету: знак 3 × 2 = 6, барьер 3 × 2 × 2 × 2 = 24, отсчёт размаха для барьера 12 × 2 = 24, «прошлый
знак» 3. Розыгрыши отсчёта — 50 на каждого из 30 кандидатов, отдельной строкой.

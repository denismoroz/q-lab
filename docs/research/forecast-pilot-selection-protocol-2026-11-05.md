# Прогноз на одной монете: отбор признаков — дополнение к протоколу (2026-11-05)

Записано до расчёта. Владелец: «да, добавляй». Делается на варианте «основа + стандартный набор» (58
признаков), **только на первом отрезке**; последняя треть отбор не видит.

1. **Группы похожих признаков.** На часах первого отрезка (2022-01 … 2024-06-12) — ранговая связь (Спирмен)
   всех пар признаков; расстояние 1 − |связь|; иерархическое объединение по среднему расстоянию; разрез на
   расстоянии **0.3** (связь по модулю ≥ 0.7 — одна группа). Группы — в отчёте.
2. **Важность групп** — по бустингу (лист ≥ 1 000, как в сетке), внутри первого отрезка, с теми же
   переобучениями раз в полгода, паузой и проверочными полугодиями 2022-01 … 2024-06:
   - **перестановка группы (кластерный MDA)**: столбцы группы целиком перемешиваются блоками по суткам на
     проверочном полугодии; важность — падение связи (регрессия) или AUC (классы), среднее по полугодиям;
   - **проверка с тенью (как Boruta)**: в обучение добавляется перемешанная блоками копия каждого признака
     («тень»); 5 прогонов с разными перемешиваниями на последнем переобучении первого отрезка (2024-01);
     группа **сохраняется**, если её важность (перестановкой) выше важности её тени не меньше чем в **4 из 5**
     прогонов **и** её средний MDA больше нуля;
   - **важность одной группы (SFI)** — бустинг только на этой группе, связь / AUC на проверочных полугодиях —
     для четырёх целей (z-доход за 1 день и 7 дней; «падение» и «рост» за 1 день, k = 1);
   - SHAP — **не считается**: библиотеки `shap` в окружении нет, а ставить новое без разрешения нельзя; вместо
     этого — важность перестановкой отдельных признаков (MDA по признаку) для тех же четырёх целей.
3. **Переобучение на отобранном наборе** — для лучшей модели каждой цели (выбранной по первому отрезку в
   варианте «основа + стандартный набор»), только на отобранных группах; на последней трети — рядом с моделью
   на всех признаках (связь / AUC с интервалами).
4. **Устойчивость отбора** — какие группы имеют MDA > 0 на каждом из пяти проверочных полугодий первого
   отрезка.

Правило остановки — то же (перемешанная цель).

**Испытаний:** отбор — по одному на цель (20); переобучение на отобранном наборе — 20; всего **40**.
